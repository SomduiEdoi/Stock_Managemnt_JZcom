# Incremental Release: 2026-10-27

## Scope

- Asset creation from an existing stock inherits its effective serial/quantity tracking. Native NEW/USED condition is accepted on create and preserved on edit.
- Condition badges appear in asset detail/edit and optional inventory columns; inventory filtering preserves condition in navigation URLs.
- Type prefixes are unique within one category, not across an entire warehouse. Existing codes remain immutable; no schema migration is included.
- Signed return PDF selection is a local draft. Preview opens before explicit confirmation (`Comfirm`, current UI label). The assigned Storeman may replace uploaded evidence until any final Storeman approval starts. Backend final-approval guards remain authoritative.
- Return-derived sale documents reuse approved snapshots from the matching return round for requester, approver and Storeman; pricing authorization remains on the derived sale. No extra approval or live-signature fallback is introduced.
- Damage PDF executive-name parentheses provide handwriting space. Cached/generated PDFs are not retroactively rewritten.
- Dashboard Recently and Activity Feed asset names link to detail; inactive assets display a deleted-asset notification, including clicks on older activity entries.
- Automatic BSD acknowledgement creation is removed. Warehouse-manager acknowledgement and BSD sale pricing remain unchanged.
